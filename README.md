# geods
Python environment for Geospatial Data Science

### Installation on a UNIX-like system
- Open the terminal and type in the command below:
`conda create --file geods.yml`
- Verify that the new environment was installed correctly:
`conda env list`
- Activate the new environment:
`conda activate geods`
### Mac Users:
- If you have a Mac with an Intel processor use `geods.yml`.
- If your Mac has an M1ARM processor (or higher) then use `geodsM1ARM.yml` instead and replace `geods.yml` with `geodsM1ARM.yml` in the instructions above.
